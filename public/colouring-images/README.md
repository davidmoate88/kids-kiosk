# Your own colouring pictures

Drop `.jpg`, `.jpeg`, `.png`, or `.webp` files straight into this folder and they'll
show up in the Colouring section automatically — no code changes needed, just a
git push to redeploy.

- The filename becomes the picture's name, so `dragon.jpg` shows up as "Dragon".
  Use hyphens/underscores for spaces: `race-car.png` → "Race Car".
- Best results: a bold black outline on a plain white/light background (like a
  scanned or photographed line drawing) — the tap-to-fill tool looks for the
  outline to know where one colour region ends and the next begins. Photos with
  soft/blurry lines, shadows, or busy backgrounds may cause the colour to leak
  outside the lines.
- Keep the photo reasonably lit and square-on (not at a steep angle) for the
  cleanest fill.
